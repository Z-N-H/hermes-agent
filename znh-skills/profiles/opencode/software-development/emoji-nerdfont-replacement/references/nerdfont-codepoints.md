the icon from (`fa` = FontAwesome, `md` = Material Design, etc.).

## Common names that DO NOT EXIST in v3.4.0

These come up frequently in older guides; do not use them:

- `nf-fa-times_circle` (use `nf-fa-circle_xmark`)
- `nf-fa-circle_xmark` exists, `nf-fa-circle_x` does not
- `nf-fa-search` (use `nf-fa-magnifying_glass`)
- `nf-fa-volume_up`, `nf-fa-volume_down`, `nf-fa-volume_mute`
  (use `nf-fa-volume_high`, `nf-fa-volume_low`, `nf-fa-volume_xmark`)
- `nf-fa-mobile` (use `nf-fa-mobile_screen`)
- `nf-fa-mobile_screen_button` (use `nf-fa-mobile_screen`)
- `nf-fa-tools` (use `nf-fa-screwdriver_wrench`)
- `nf-fa-wrench` (use `nf-fa-screwdriver_wrench`)
- `nf-fa-hammer` (use `nf-fa-screwdriver_wrench`)
- `nf-fa-cog` (use `nf-fa-gear`)
- `nf-fa-cogs` (use `nf-fa-gears`)
- `nf-fa-tint` (use `nf-fa-droplet`)
- `nf-fa-burst` (use `nf-fa-explosion`)
- `nf-fa-trash` (use `nf-fa-trash_can`)
- `nf-fa-newspaper` (use `nf-fa-newspaper` — actually exists, but renamed from `fa-newspaper-o` in v6)
- `nf-fa-bar-chart` (use `nf-fa-chart_bar`)
- `nf-md-chart-bar` (use `nf-md-chart_bar`)
- `nf-md-trending-up` (use `nf-md-trending_up`)
- `nf-md-trending-down` (use `nf-md-trending_down`)
- `nf-md-close-circle` (use `nf-md-close_circle`)

## Verifying a new mapping yourself

```bash
# Download the authoritative JSON
curl -sL https://raw.githubusercontent.com/ryanoasis/nerd-fonts/master/glyphnames.json \
  -o /tmp/nf.json

# Check if a mapping exists
python3 -c "import json; d=json.load(open('/tmp/nf.json')); print(d.get('fa-times_circle', 'NOT FOUND'))"

# Get the codepoint
python3 -c "import json; d=json.load(open('/tmp/nf.json')); print(d['fa-circle_xmark']['code'])"
```

If the JSON does not contain the key you want, the icon name is wrong
(or the icon does not exist in the font set you're targeting).
